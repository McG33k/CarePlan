== Description ==
CarePlan helps care and disability service providers manage participant care plans and support coordination workflows.

This plugin is independent and not affiliated with any government agency.

== Installation ==
1. Upload the plugin files to `/wp-content/plugins/careplan`
2. Activate the plugin through the Plugins screen
